## 2. 范围（含「不做什么」）

覆盖：

- 多道录音题全部成功 → 本页自动提交、函数返回 True

- TTS 关闭且题目需要原声 → 跳过该题，最终判未完成
- 需要 AI 写稿但未配置 AI → `_last_tab_outcome='skipped_no_ai'`，返回 False
- 跟读题（ORAL_ALOUD）→ 不生成脚本

不做：

- 本轮**不抽代码**、不改任何行为
- 不覆盖音视频预处理的真实播放
- 不覆盖 AI 分支（官方答案/模型作答）——后续单独建基线
